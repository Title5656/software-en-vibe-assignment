# ฟีเจอร์เพิ่มเติมที่ 2: ตารางกิจกรรมรายสัปดาห์

## Prompt สำหรับ vibe coding

เพิ่มหน้าตารางกิจกรรมรายสัปดาห์ในเว็บไซต์ MUICT Clubs พร้อมลิงก์ Activities ในเมนู แสดงกิจกรรมตามวันและวันที่ตั้งแต่จันทร์ถึงอาทิตย์ สามารถเลื่อนไปสัปดาห์ก่อนหน้า สัปดาห์ถัดไป กลับสัปดาห์ปัจจุบัน และเลือกวันที่เพื่อดูเฉพาะกิจกรรมวันนั้นได้ เพิ่มกิจกรรมเดโม 7 รายการ วันละ 1 กิจกรรม ให้ตารางไม่ว่างและพร้อมนำเสนอ โดยระบุชัดเจนว่าเป็นข้อมูลเดโมที่แสดงซ้ำในแต่ละสัปดาห์ แต่ละกิจกรรมต้องมีชื่อ เวลา สถานที่ รายละเอียด สิ่งที่ควรเตรียม และชมรมผู้จัด พร้อมลิงก์ไปหน้าชมรม ใช้วันที่ปัจจุบันตามเวลาไทย รองรับหน้าจอมือถือ รักษารูปแบบเว็บไซต์และฟีเจอร์เดิม ทดสอบการเลื่อนสัปดาห์ การเลือกวันที่ และการเปิดรายละเอียด พร้อมบันทึกภาพผลลัพธ์และตารางสรุปสำหรับส่งอาจารย์

## Prompt เพิ่มเติมสำหรับปรับปรุง

ปรับช่องเลือกวันที่ให้เริ่มว่างเมื่อแสดงทั้งสัปดาห์ เพื่อให้เลือกวันจันทร์ของสัปดาห์นั้นได้ทันที โดยยังคงแสดงกิจกรรมครบ 7 รายการก่อนเลือกวันที่

เหตุผล: การตรวจโค้ดและทดสอบหน้าจอพบว่าการแสดงวันจันทร์เป็นค่าเริ่มต้นทำให้เลือกวันจันทร์เดิมเพื่อกรองไม่ได้ เพิ่มการทดสอบที่ยืนยันปัญหาก่อนแก้ไข

## หมายเหตุการตรวจสอบ

- ทดสอบวันที่ 25 ตุลาคม 2026 ตามเวลา Asia/Bangkok
- กิจกรรมเป็นข้อมูลสมมติสำหรับงานส่งอาจารย์และแสดงซ้ำทุกสัปดาห์ โดยมีข้อความ Demo กำกับชัดเจน
- ทดสอบคำนวณสัปดาห์เริ่มวันจันทร์ การข้ามเดือน/ปี และวันปัจจุบันตามเวลาไทย
- ตรวจพบและแก้ปัญหาการเลือกวันจันทร์ด้วย regression test ที่ล้มเหลวก่อนแก้และผ่านหลังแก้
- เครื่องมือกรอกวันที่อัตโนมัติตั้งค่า DOM ได้แต่ไม่ส่ง change event จึงตรวจเพิ่มเติมด้วยการเปลี่ยนวันผ่านคีย์บอร์ดและการทดสอบ React โดยตรง ทั้งสองวิธียืนยันการกรองวันที่ได้
- TypeScript ยังพบข้อผิดพลาดเดิมสองจุดใน `vite.config.ts:11` เกี่ยวกับ `process.env.GITHUB_REPOSITORY` ไม่มีข้อผิดพลาดในฟีเจอร์นี้
- ฟีเจอร์นี้ยังเป็นการแก้ไขในเครื่อง ไม่มีการ commit/push/deploy เพิ่มหลังเวอร์ชัน `b3bc006`
